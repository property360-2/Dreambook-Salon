# Metric Calculation Proof and Implementation

This document provides the mathematical formulas and Python implementation details for the metrics used in Chapter 4.



## 1. Classification Metrics (Customer Retention)

The **Linear Logistic Regression** classification model predicts a binary outcome (1 = Return, 0 = No Return).

### Mathematical Formulas

*   **Accuracy:**
    $$Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$$
    *TP: True Positive, TN: True Negative, FP: False Positive, FN: False Negative.*

*   **Precision:**
    $$Precision = \frac{TP}{TP + FP}$$

*   **Recall (Sensitivity):**
    $$Recall = \frac{TP}{TP + FN}$$

*   **F1-Score:**
    $$F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}$$

### Python Implementation (scikit-learn)

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

# Sample Data (Actual vs Predicted)
# 1: Customer Returned, 0: Customer Did Not Return
y_true = [1, 0, 1, 1, 0, 1, 0, 1]
y_pred = [1, 0, 1, 0, 0, 1, 1, 1]

accuracy = accuracy_score(y_true, y_pred)
precision = precision_score(y_true, y_pred)
recall = recall_score(y_true, y_pred)
f1 = f1_score(y_true, y_pred)

print(f"Accuracy: {accuracy}")
print(f"Precision: {precision}")
print(f"Recall: {recall}")
print(f"F1 Score: {f1}")
```
